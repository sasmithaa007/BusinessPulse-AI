# Synthetic Dataset Dictionary

All records generated by BusinessPulse AI are synthetic and produced with fixed random seeds for reproducibility.

---

## 1. `customers` Table
| Column | Type | Description | Example Values |
|---|---|---|---|
| `id` | Integer (PK) | Unique customer ID | `1`, `2` |
| `customer_code` | String(64) | Unique tracking code | `CUST-FT-10294` |
| `name` | String(255) | Synthetic Indian name | `Aarav Sharma`, `Priya Patel` |
| `email` | String(320) | Customer email address | `aarav.sharma@example.com` |
| `customer_type` | String(20) | Individual or Business entity | `individual`, `business` |
| `business_scenario` | String(50) | Domain context | `fintech`, `saas`, `developer_tools` |
| `signup_date` | Date | Account creation date | `2024-03-15` |
| `country` | String(100) | Primary jurisdiction | `India` |
| `status` | String(20) | Current lifecycle state | `active`, `inactive`, `churned` |
| `segment` | String(20) | Value tier | `basic`, `standard`, `premium`, `enterprise` |
| `lifetime_value` | Numeric(14,2) | Aggregated historical spend (₹) | `45200.00` |
| `churn_risk_score` | Numeric(5,4) | Propensity score (0.0 to 1.0) | `0.1840` |

## 2. `transactions` Table
| Column | Type | Description | Example Values |
|---|---|---|---|
| `id` | Integer (PK) | Transaction ID | `1001` |
| `customer_id` | Integer (FK) | References `customers.id` | `42` |
| `transaction_code` | String(64) | Unique payment reference | `TXN-202409-91823` |
| `transaction_date` | Timestamp | Transaction timestamp | `2024-08-14 11:24:00` |
| `amount` | Numeric(12,2) | Transaction value in INR (₹) | `4999.00` |
| `status` | String(20) | Final settlement outcome | `success`, `failed`, `pending`, `refunded` |
| `payment_method` | String(30) | Instrument used | `upi`, `netbanking`, `card`, `wallet` |
| `failure_reason` | String(500) | Diagnostic error if failed | `Insufficient funds`, `Bank timeout` |
| `gateway` | String(100) | Payment gateway | `Razorpay`, `Juspay`, `Stripe` |
| `processing_time_ms`| Integer | Gateway response latency | `412` |
